미디어 제작실

이번 주 입력을 모아 제작 가능 여부부터 확인합니다.

새 제작

새 작업은 항상 빈 상태로 시작합니다. 지난주 정보는 자동으로 가져오지 않습니다.

기존 PPT·PDF 미리보기 (선택)

이미 만든 자료를 화면에서 확인할 때만 사용해요. 새로 제작한 파일은 다시 올릴 필요가 없어요. 업로드한 검수용 복사본은 24시간 후 정리 대상이며, 원본은 변경하지 않아요.

PDF 미리보기는 영상·음원·애니메이션 재생 또는 실제 인쇄 확인을 대신하지 않습니다.

제작 목록

1. 이번 주 자료 등록

자료 유형을 선택하면 저장 위치가 자동 결정됩니다. 최신 수정 안내는 누적 보관되며 기존 입력은 덮어쓰지 않습니다.

    2. 안내 해석 검토

    이번 작업의 원문과 수정 안내만 해석합니다. 상태와 값, 최종 변경 출처를 확인하세요. 인식하지 못한 문장은 자동 확정하지 않습니다.

    확정 시 이번 작업의 안내 해석 YAML을 새로 기록합니다. 기존 파일을 덮어쓰지 않으므로 확정 후 수정은 새 작업에서 진행합니다. 확정은 악보/본문·실제 화면 검수가 아닙니다.

    3. 주일·주보 공통 정보

    같은 날짜의 주일 작업만 명시적으로 선택해 가져올 수 있습니다. 설교 제목과 본문 등 공통 정보를 확인하며, 주보 원문과 전체 교차검수는 별도입니다.

    4. 제작 전 필수자료 확인

    안내 원문만 올리면 입력 정리가 끝난 것이 아닙니다. 해석·수정 지시 확인 후 생성된 이번 주 자료가 있어야 합니다. UNSET은 미제공, NONE은 이번 주 없음, VALUE는 이번 주 값 제공입니다.

    5. 제작 및 결과

    생성 완료는 화면 검수, 실제 인쇄·접지, 동영상·음원 재생 또는 자료 사용 허락을 의미하지 않습니다.

    6. 제작 결과 미리보기

    웹에서 생성된 PPT·PDF를 다시 업로드하지 않고 화면에서 확인할 수 있습니다. 미리보기 PDF는 임시 캐시이고, 실제 제작 파일은 별도 보관됩니다.

    생성된 파일이 있으면 미리보기가 표시됩니다.
