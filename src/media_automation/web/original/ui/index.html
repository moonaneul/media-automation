연결 상태 확인 중

OneDrive에 찬양 원본과 완료본을 보관합니다. 제작에 사용하는 원본은 서버에도 내려받아 사용합니다. 아래에서 계정 연결과 폴더를 지정하세요.

처음 연결할 때 · Microsoft 앱 설정

Microsoft 앱의 Authentication → Add a platform → Web에 아래 반환 주소를 등록하세요. SPA나 모바일 플랫폼을 선택하지 않습니다. 로컬 로그인은 Microsoft가 허용하는 localhost 주소로 이동해 진행합니다.

Certificates & secrets → New client secret에서 비밀을 만들고 아래에 Value를 입력하세요. Secret ID와는 다릅니다. 암호·비밀 값은 채팅으로 보내지 마세요. 비밀 만료 전에 갱신해야 합니다.

Files.ReadWrite 권한은 개인 파일 전체에 접근할 수 있습니다. 사이트는 지정한 두 폴더만 처리하며 원격 파일 삭제 기능은 제공하지 않습니다.

처음에는 위의 Microsoft 앱 설정을 저장한 뒤 OneDrive를 연결하세요. 연결 후 아래 두 폴더를 선택할 수 있습니다.
