# 가을 주보 새 디자인 시안

기존 제작 경로를 변경하지 않고 별도 시안으로 생성한다.

```sh
python scripts/build_modern_bulletin.py --weekly output/bulletin_intake/sunday-20260927-bulletin.yaml --output output/bulletin/20260927_주보_가을리디자인_v1.pdf
```

## 제작 및 검수

- 각 논리 페이지의 입력은 기존 BulletinDocument와 동일하다.
- 날짜 2026-09-27, 호수 13-39를 유지했다.
- 새 가을 사진은 AI 생성이며 생성 기록은 assets/bulletin/autumn_editorial_v1_prompt.md (최초 생성) 및 autumn_soft_v2_prompt.md (경계 편집)에 보관했다.
- 사용자의 최신 지시로 사진 아래의 여호와께 감사하라 / 시 136:1 문구를 삭제했다. 표지 상단 마 28:19는 유지한다.
- 옛 사진 배경이 남는 로고 이미지 조각을 제거했다. 교회명과 성서침례 표기를 검정 텍스트로 직접 조판하고 하단 정보와 왼쪽 정렬을 맞췄다.
- 표지 연락처, 예배 순서, 섬김 명단, 목장 본문/제목/질문, 광고/일정/정기모임/사명/핵심가치를 같은 쪽에 유지했다.
- PDF에서 논리 페이지별 94개 텍스트 항목을 대조해 누락 0개를 확인했다.
- A4 가로 2페이지, 4|1 / 2|3이며 텍스트 색상은 모두 검정이다.
- 두 면을 150dpi로 렌더링하여 화면 검수했다. 실제 양면 인쇄는 수행하지 않았다.
- 기존 파일은 보존한다. 새 디자인은 사용자 검토용이며 기본 템플릿으로 자동 승격하지 않는다.
