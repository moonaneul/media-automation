# 웹앱용 공통 제작 작업 기반

ProductionJobs는 기존 수요·주일·금요·주보 CLI를 별도 작업 폴더에서 실행한다.
독립 작업 ID를 발급하고 코드·확정된 주보 디자인 자산만 복사한다.
주간 데이터, 성경 자료, 찬양, 원본 PPT와 이전 결과물은 자동 승계하지 않는다.
필요한 입력 파일은 해당 작업에 명시적으로 등록한다.

- create(service, date): 작업 준비, 상태 needs_input
- stage(job_id, source, relative): 필요한 파일 복사, 기존 입력 덮어쓰기 금지
- run(job_id, source=...): 제작 후 구조화된 JobResult 반환
- 결과 상태: generated 또는 failed, 종료 코드, 상대 산출물 경로, 로그 경로
- generated는 파일 생성 상태이며 화면·인쇄·미디어 재생 검수 완료를 뜻하지 않는다.
- 실패한 작업의 부분 산출물은 다운로드 목록에서 제외한다.
- 같은 작업 중복 실행과 실행 중 입력 교체는 차단한다.
- 새로 만들어지거나 변경된 PDF/PPTX만 결과 목록에 포함한다.

작업 폴더 분리는 OS 보안 샌드박스가 아니다. 현재는 로컬의 신뢰된 호출용이며
공개 API로 직접 노출하지 않는다. 웹 단계에서 업로드 검증, 접근 권한,
로그의 개인정보 처리, 취소 및 하위 프로세스 종료, 보관 정책을 연결해야 한다.

## 확정 디자인

사용자가 가을 주보 새 디자인을 확정했다. bulletin.py complete의 기본 디자인은
modern이며 --design classic으로 이전 서식을 선택할 수 있다.
새 디자인은 autumn_soft_v2.png를 사용하고 사진 아래 시 136:1 문구는 삭제했다.
상단 마 28:19와 검정 텍스트, 13-39호, 쪽별 내용과 4|1 / 2|3 배치를 유지한다.
정식 교회명과 연락처는 가운데 정렬한다. 확정본은 기존 비교본과 별도로 보존했다.
