# 제작 및 원본 웹 입력 코드 통합 — 2026-10-13

기준은 main의 0e1d208이다. 원본 API 복구와 주일 HWP 입력 브랜치의
코드/테스트를 결합했다. 기존 작업 브랜치의 주간 입력, 미디어, 결과물 및
해당 파일을 포함한 커밋 이력은 이 브랜치에 추가하지 않았다.

원본 서버는 _legacy_migration/ui/index.html을 사용하며 기존 쿠키 로그인과
저장/첨부 API를 유지한다. 제공하는 화면에 주일 HWP 보조 기능을 연결했다.
날짜 불일치, 기존 입력 보존, 섬김표 검토 및 목장 본문 재사용 확인을 유지한다.
공식 서버의 제작/검수 기능과 원본 복구 실행기는 각각 보존했다.

검증: Python 3.12, NanumGothic-Regular.ttf를 MEDIA_BULLETIN_FONT로 지정.
전체 이력이 있는 통합 작업본에서 pytest 313 통과, 2 건너뜀.
코드 전용 브랜치는 주보 표지 파일을 포함하지 않아 처음에는 311 통과,
2 실패(표지 파일 누락), 2 건너뜀이었다. 별도 테스트 복사본에만 표지를
제공한 재검사도 313 통과, 2 건너뜀으로 완료했다. 글꼴과 표지 파일은 코드 커밋에 포함하지 않는다.
브라우저 육안 확인, 실제 주간 자료로
PPT 제작, PowerPoint 미디어 재생, OneDrive 및 온라인 운영은 미검증이다.

맥북의 기존 미커밋 입력/PPT와 SQLite 데이터는 이 작업에서 접근하거나
변경하지 않았다. 검증용 실행기는 scripts/run_original_blue.py이며,
기존 실행 환경과 다른 포트 및 새 임시 DB를 명시해서 확인한다.
예: python scripts/run_original_blue.py --port 18768 --database /tmp/media-blue-review.sqlite

이 브랜치에는 필요한 교회 템플릿/미디어를 새로 옮기지 않았다.
자동 테스트 통과는 실제 예배 자료의 완성을 의미하지 않는다.
