# 금요 Zoom 전체 성경 JSON 연결

## 한 번만 설치

전달받은 수정 성경 압축파일의 `bible_fixed.json`을 저장소의
`data/private/bible_fixed.json`에 둔다. 이 경로도 git으로 동기화하므로 새 컴퓨터에서 다시 복사할 필요가 없다.
원본과 수정 기록은 전달받은 압축파일에 보존되어 있다.

이 JSON은 사용자 제공 자료이며 전체 원문 대조 검수 완료를 의미하지 않는다.
성경을 생성하거나 다른 번역으로 대체하지 않는다.

## 주간 사용

```bash
python friday.py paste
```

금요 안내의 `[금요 기도회 순서] 10/9`, 곡 번호 1)~5), 기도 구역 제목,
`고전 3:16 / 설교 제목`, `읽을 말씀 – ...` 형식을 지원한다.
연도가 없는 날짜는 실행하는 해를 사용한다. 연도를 명시할 수도 있다.

개인 기도는 사용자가 확인한 고정 마지막 순서이므로 생략돼도 포함한다.
해당 주에 개인 기도를 명시적으로 빈 항목으로 주면 그 지시는 유지한다.

추가 말씀의 쉼표로 나열된 주소는 각각 조회하고 서로 다른 본문 화면으로 만든다.
기도 설명에 성경 주소만 한 줄로 적으면 본문을 채운다. 예:

```text
1. 기도 제목
 - 빌 4:6~7
```

일반 기도 문장과 이미 전달된 본문은 임의로 다시 쓰지 않는다.

## 통합 절

개역개정에서 본래 묶인 신 6:18~19 같은 범위는 한 본문 단위로 표시한다.
각 번호에 같은 원문을 복제하지 않는다. 통합 범위 일부만 요청하면 멈추고
정확한 통합 범위를 알려준다. 장을 넘는 범위는 현재 JSON 조회에서 지원하지 않는다.

기존의 등록된 범위 본문은 먼저 사용한다. 범위 본문에 없으면 전체 JSON,
JSON이 없으면 기존 검증 마스터를 조회한다. JSON에 요청 절이 없거나 잘못된 키가
있으면 중단하며 임의로 보충하지 않는다.

## 검수와 남은 단계

안내→성경→주간 입력과 본문 구조 생성은 자동 테스트로 확인한다.
최종 PPT는 해당 주 MP4와 공통 기도 MP3를 연결한 뒤 제작한다.
PowerPoint의 실제 화면, 기도 애니메이션, 영상·음원 재생은 윈도우에서 따로 확인한다.
