## 5. 후속 설계 — 아직 미구현

**OneDrive를 원본·완성본 장기 보관소로, 서버를 임시 제작 작업 공간으로 사용**한다는 사용자 방침.

- DB에는 예배별 입력, 원본의 OneDrive ID/버전·해시, 검수 기록, 생성 결과 상태만 영속 저장하는 방향을 검토한다.
- 사용자가 선택한 원본만 일시 다운로드. 동일 곡은 OneDrive 메타데이터로 재식별하고 파일 변경 시 재확인한다.
- 서버 영구 원본 복사본, 지난 PPT, 생성된 미디어 포함 결과물의 자동 정리는 **업로드 신뢰성·복구·참조 안전성 검증 후** 별도 작업으로 시행한다. 당장은 어떤 원본도 자동 삭제하지 않는다.
- 큰 금요 MP4 포함 PPT의 임시 공간 피크, 제작 중 오류 시 복구, OneDrive 업로드 실패 시 재시도와 저장 공간 한도를 먼저 검증한다.
- 자료 보유 여부와 교회의 원본 사용 허락은 별개 기록으로 유지한다.
