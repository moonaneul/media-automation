## 결과

PDF 생성 기능과 인쇄 배치는 구현되어 있지만 기존 디자인 재현은 미완료다.
A4 가로 2페이지이며 4|1, 2|3 순서다. 한글 글꼴을 포함해 재생성한 두 면을
실제 렌더링하여 확인했다. 주요 내용의 잘림이나 겹침은 보이지 않았다.
물리적 양면 출력과 접기는 수행하지 않았다.

기존 PDF는 비내장 CID 글꼴을 사용하여 현재 Poppler에서 한글이 표시되지
않았다. 생성 코드가 한글 TTF를 PDF에 포함하도록 수정했으며, PDF에
FontFile2가 포함되는 회귀 테스트를 추가했다. macOS는 AppleMyungjo,
Windows는 맑은 고딕, Linux는 설치된 NanumMyeongjo를 찾는다.
MEDIA_BULLETIN_FONT로 한글 TTF 경로를 명시할 수 있다. 해당 글꼴이 없으면
조용히 대체하지 않고 오류를 반환한다. 서버에는 별도 글꼴 준비가 필요하다.

## 남은 작업

1. 표지 배경과 로고를 독립 자산으로 확보해 기존 표지 구성을 재현한다.
   날짜가 찍힌 과거 표지 전체를 새 표지로 복사하지 않는다.
2. 기존 주보의 고딕체, 파란 제목, 구분선, 표와 목장 나눔 테두리를 반영한다.
3. 9/27 호수는 기존 같은 주 주보용 데이터에 13-39로 저장되어 있었다.
   최초 검수본이 주일 PPT용 데이터를 사용하여 누락했다. 상태에 복원하고
   검수본을 재생성했다. PDF 빌더도 호수 누락 시 생성을 차단한다.
4. 인도자·찬양 인도·설교자·폐회기도 등의 미제공 주간 필드를 검토한다.
   과거 명단을 승계하지 않는다.
5. 실제 인쇄 후 접지 위치와 여백을 확인한다.

이번 검수본은 디자인 완성본이 아니다. 기존 출력본과 원본 자료는 보존했다.
웹 MVP 개발은 병행 가능하지만 주보를 검수 완료 산출물로 표시하지 않는다.
