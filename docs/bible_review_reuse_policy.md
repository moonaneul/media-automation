# 개역개정 성경 본문 검수 기록 — 안전한 재사용

이 기능은 **독립적인 개역개정 원문 자동 대조 기능이 아니다.** 사용자 제공 Bible JSON을 그대로 공식 개역개정으로 인증하거나 교회 외부에 전문을 전송하지 않는다. 검수된 자료만 믿고 사용할 수 있도록 다음 두 경로를 구분한다.

## 경로 A: 별도 검수된 개역개정 본문 원본

환경변수 `MEDIA_BIBLE_SOURCES`로 지정한 비공개 디렉터리의 `validated: true`, `translation: 개역개정` YAML에 해당 요청 구절 **전체**가 포함되어 있으면 기존 `bible_connection.resolve()`가 이를 사용한다. 원본 자체의 정확성, 출처 및 사용 허락은 **별도 확인**이 필요하다. 수요·주일은 한 절 한 화면, 금요 Zoom은 예배 형식을 유지한다.

## 경로 B: 한 번 직접 대조한 사용자 제공 JSON의 재사용

본문이 비공개 `MEDIA_BIBLE_FILE` JSON에만 있으면 처음 제작 시 `:bible_review`가 남는다. 작업자는 실제 PPT를 개역개정과 대조하고 절 번호, 본문 범위, 누락, 중복, 오탈자, `세례→침례` 화면 표기를 확인해야 한다. 기존 수동 승인 질문에서 명시적으로 확인한 경우에만 검수 완료 처리한다.

새 코드로 제작한 PPT에는 검수 대상 구절별 암호학적 지문(SHA-256)이 저장되며, 서버는 **승인 당시 파일과 구절이 같은지** 재확인한다. 확인이 일치하면 DB의 `bible_review_receipts`에 **구절 주소, 정확한 원문 기반 해시, 확인 날짜/예배/파일 ID, 확인 시각**만 저장한다. 본문 전문은 이 테이블에 저장하지 않는다. 이 기록은 다른 주차·다른 예배에서도 재사용할 수 있지만, **주소와 정확한 원문이 모두 일치하는 모든 절**에서만 적용된다.

한 글자라도 변하거나, 통합 절 범위를 다르게 요청하거나, 요청 구간의 일부만 기록된 경우에는 다시 `:bible_review` 경고가 생긴다. 이미 만들어진 구형 PPT에는 구절 지문이 없으므로, 이 새 기록에 소급하여 임의 등록하지 않는다. 이전에 완료 표시된 PPT나 OneDrive 파일은 변경하거나 삭제하지 않는다.

예배 PPT 화면에는 ‘이전에 직접 대조한 구절과 같은 본문’으로 표시하며 이를 ‘독립 원문 자동 검증’이라고 부르지 않는다. 추가 말씀 1·2 같은 각 구절의 본문도 동일한 절 단위 기준으로 처리한다. 기도제목 속 자유로운 문장 인용은 완전한 구절 지문이 있는 경우에만 재사용 가능하며, 그렇지 않으면 수동 확인을 유지한다.

**주의:** 성경 원문에 대한 권리 보유나 자료 사용 허락 여부는 검수 기록만으로 증명되지 않는다. 실제 PPT 이미지에 쓰인 글씨 잘림과 음원·영상 재생 검수 역시 이 기능으로 대체할 수 없다.

### 테스트 검증

- 자료 없음: 자동 검증 미완료 유지
- 첫 승인: 정확한 구절 해시만 저장
- 동일 구절 반복 사용: 이전 수동 대조 기록 재사용
- 일부 구절만 승인된 범위: 검수 미완료 유지
- 본문 글자 또는 주소가 달라짐: 재검수
- JSON이 PPT 생성 이후 변경됨: 승인 거부, 현재 생성본 보존
- 통합 절 일부 요청: 누락 오류
- 화면 표기에서 `세례→침례` 별도 유지
- 기존 승인된 PPT·기존 OneDrive 완료 파일: 변경 없음
