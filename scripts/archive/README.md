# 보관된 이전 실행 스크립트

이 폴더의 스크립트는 현재 사용자의 수요·금요·주일 명령어와 별개인 **과거 작업 이력**이다.

현재 명령어 진입점은 루트 `wednesday.py`, `friday.py`, `sunday.py`, `bulletin.py`이며, 로컬 웹은 `webapp.py`이다.

- 여기의 예전 제작 스크립트를 현재 실사용 예배 자료로 자동 실행하지 않는다.
- 사용자 원본/이전 주 산출물을 임의 덮어쓰거나 삭제하지 않는다.
- 기존 스크립트 경로를 이동·삭제하려면 호출처, 복구 필요성과 테스트를 먼저 확인한다.
