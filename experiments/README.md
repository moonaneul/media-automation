# 과거 실험 코드 및 스냅샷 — 보존 영역

`desktop-webapp-20261010/` 안의 `output/service-design/`은 **2026-10-10 당시 코드 개발 스냅샷**이다. 폴더 이름의 `output`은 예배 결과물 저장소와 무관하다.

- 공식 현재 소스는 저장소 루트 `src/media_automation/`의 활성 패키지와 CLI이다.
- 이 폴더를 별도 서버로 배포하거나 실사용 작업 DB와 연결하지 않는다.
- 현재 코드와 같은 파일명/내용이 있다는 이유만으로 이 스냅샷을 삭제하거나 덮어쓰지 않는다.
- 사용처/유래/복구 필요성이 확인된 이후에만 정리 방향을 결정한다.
- 실제 교회 원본 `sources/`, 주간 입력 `input/`, 완성본 `output/`은 이곳으로 옮기지 않는다.
