# Church Media Automation

비공개 저장소용 코드 스냅샷. 수요·주일·금요 PPT 및 주보 제작 웹앱.

## 포함 범위
웹 화면, 제작 엔진, 파일 병합·변환 및 검사 코드.

## 제외 범위
주간 입력 DB, 첨부 원본, 영상·음원·악보·템플릿·완성 파일, 성경 데이터, 비밀번호 및 인증키. 제외된 자료는 기존 OneDrive 연결 후 별도 공급해야 합니다. 코드만으로 전체 제작이 바로 실행되는 패키지는 아닙니다. 일부 런타임·성경 소스 경로는 현재 맥북 환경을 참조하며 Linux 이전 작업이 남아 있습니다.

## 상태
로컬 및 휴대폰 제작 검수 완료. 온라인 운영·OneDrive 원격 원본 삽입은 미검증.

공개 저장소 보관본에는 예시 담당자와 로컬 사용자 경로를 익명화했다. 운영 중인 로컬 코드는 별도이며 여기 파일은 작업 인수인계용 스냅샷이다. 기존 src/ 엔진을 대체하지 않는다.
